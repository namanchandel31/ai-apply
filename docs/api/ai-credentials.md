# AI credentials API

JWT required. Prefix `/api/ai`.

| Method | Path |
|--------|------|
| GET | `/providers` |
| GET | `/credentials` |
| POST | `/credentials` |
| PUT | `/credentials/chain` |
| POST | `/credentials/test` |
| PATCH | `/credentials/:id` |
| POST | `/credentials/:id/health-check` |
| POST | `/credentials/:id/activate` |
| DELETE | `/credentials/:id` |
